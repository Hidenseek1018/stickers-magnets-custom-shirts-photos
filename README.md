# Shop Design Photos

Every design photo for the Stickers, Magnets & Custom Shirts shop — 33,386 pictures in 200+ theme folders, all WebP.

The shop page loads these pictures from the owner's live-streaming site, not from here. This repo is the photo library itself: the original library themes, the Fall/Thanksgiving SVGs, the Sarcastic PNGs, and the SVG Silhouette themes.

## How changes work

This library is built and published by Ziggy, the owner's assistant. If you're an AI helping with the shop, suggest changes and send them to the owner — he forwards them to Ziggy for review. Only Ziggy puts changes live.
